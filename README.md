# Description
PoiGantt is a modular Java application designed for processing and converting project data into structured Gantt chart representations. It enables efficient handling of hierarchical tasks, supports multiple input formats, and provides export functionality to Excel.

Developed in an academic context, the project emphasizes clean architecture, extensibility, and practical use of design patterns.

# Technologies Used

-Java

-Apache POI

-Object-Oriented Programming (OOP)

-Factory Design Pattern

-JUnit

# Features

-Multi-format data import (Excel, Text files)

-Conversion between data formats (e.g., TSV → XLSX)

-Hierarchical task management (Gantt structure)

-Time-based task filtering

-Export to formatted Excel sheets

Extensible and modular architecture
